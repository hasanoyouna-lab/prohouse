# سحب تلقائي لمبيعات تابسنس (غير رسمي)

سكربت بيسجل دخول تابسنس تلقائياً كل يوم، يسحب تقريرين ليوم أمس:
1. **المبيعات حسب التصنيف** → لتصنيفات دجاج / لحم / بحري.
2. **المبيعات حسب المنتج** → بس لسحب كمية منتج "أم علي" (نصف ساندويتش يُسجَّل تحته بالكاشير)،
   وبيقسمها ÷2 ويضيفها لتصنيف "فطور" (كل 2 أم علي = ساندويتش واحد).

وبعدين يبعت كل هاد لموقع Pro House عشان يقارنه مع الكميات المستلمة.

**تذكير مهم:** هاد الحل غير رسمي (مو API معتمد من تابسنس) — ممكن يتوقف يشتغل فجأة لو
تابسنس غيّروا شكل الموقع. راجع المحادثة يلي بنيت فيها هاد السكربت لمعرفة المخاطر بالتفصيل.

## الإعداد (مرة وحدة بس)

1. ثبّت [Node.js](https://nodejs.org) لو مو مثبّت عندك (نسخة 18 أو أحدث).
2. افتح PowerShell بهاد المجلد وشغّل:
   ```
   npm install
   npm run install-browser
   ```
3. انسخ `config.example.json` وسمّي النسخة `config.json`، وعبّي فيها:
   - `email` / `password`: بيانات دخولك لتابسنس (**هاد الملف ما بينرفع لأي مكان — خليه سري**).
   - `integrationToken`: التوكن يلي رح يعطيك ياه — راجع خطوة الباك اند تحت.
4. **بدّل كلمة مرور تابسنس** إذا كانت نفس الكلمة يلي انكتبت بمحادثة سابقة (لأسباب أمنية)، وحدّثها بـ `config.json`.

## تجربة يدوية

```
npm start
```

لو نجح، رح تشوف رسالة "✅ تم سحب وإرسال بيانات..." وبيانات التصنيفات.
لو فشل، رح تلاقي لقطة شاشة `downloads/error-screenshot.png` تساعدنا نفهم وين المشكلة بالضبط
(غالباً حقول تسجيل الدخول أو خانة التاريخ أو زر التصدير محتاجين تعديل بسيط بالسكربت).

## التشغيل التلقائي يومياً (Windows Task Scheduler)

1. افتح "Task Scheduler" (جدولة المهام) من قائمة ابدأ.
2. Create Task → اسم: `Pro House Tabsense Sync`.
3. Triggers → New → Daily → اختار وقت مناسب (مثلاً 6:00 صباحاً، بعد إغلاق المحل بوقت كافي).
4. Actions → New → Program/script: اكتب `node`، Add arguments: اكتب المسار الكامل لـ
   `pull-tabsense.js` (مثال: `C:\Users\husain\OneDrive\عبداللطيف جميل\prohouse\tabsense-sync\pull-tabsense.js`).
5. Start in: اكتب مسار هاد المجلد نفسه.
6. احفظ. من هلأ وطالع بيشتغل تلقائياً كل يوم بدون ما تفتحه.
